# Fontes e integridade dos dados

Fontes planejadas: IBGE (municípios), INCRA/SIGEF (parcelas), CAR/SICAR (cadastros), MapBiomas (uso do solo), IBAMA (embargos).

IBAMA: https://dadosabertos.ibama.gov.br/dataset/termos-de-embargo

**Nenhuma base ambiental foi importada.** Não indicar que uma propriedade está regular com base na ausência de registros. Qualquer interseção exige atualização, procedência e verificação oficial. O relevo 3D representa elevação, não modelo fotogramétrico de construções ou da fazenda.
